# 介绍
该代码通过指针，将两个递增的有序链表合并为一个递增的有序链表，并依次输出该链表的值

## 设计原理
从两个链表的首元结点开始，比较两个结点的数据值，把值较小的结点接到结果链表的尾部，循环执行直到且其中一条链表遍历借宿；最后将另一条链表剩下未遍历的整条结点链，直接接到结果链末尾。具体实现代码如下（typedef struct point定义链表结点结构体，包括数据域data和指针域next；linklist mergelist合并两个递增有序链表，原地复用原有结点；createlist把数组中的元素逐个生成结点，构建单链表；printlist遍历链表，依次输出每个结点的数据域的值）

## 主要功能
主要实现两个单调递增的链表的合并，形成一个新的单调递增的链表
