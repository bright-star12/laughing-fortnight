# 使用标志变量的循环队列

## 项目介绍

本项目使用 C 语言和数组实现循环队列，支持初始化、入队和出队操作。通过首尾指针及标志变量 `tag` 区分队列为空或已满，能够使用数组的全部存储位置。

源代码：[code4.c](./code4.c)。

## 主要功能

- 初始化队列状态。
- 在队尾插入整数元素。
- 从队首取出整数元素。
- 判断队列为空或已满，并拒绝无效的出队或入队操作。

## 数据结构

| 字段 | 含义 |
| --- | --- |
| `Q[MaxSize]` | 存储队列元素的数组，当前容量为 `5` |
| `front` | 队首位置，即下一次出队读取的位置 |
| `rear` | 队尾位置，即下一次入队写入的位置 |
| `tag` | 在 `front == rear` 时区分队空与队满的标志 |

## 算法原理

队列遵循先进先出原则。每次入队或出队后，通过 `(位置 + 1) % MaxSize` 更新指针，使其到达数组末尾后回到起点。

- **队空条件**：`front == rear && tag == 0`。
- **队满条件**：`front == rear && tag == 1`。
- 当 `front != rear` 时，队列既不为空，也未满，不能仅凭 `tag` 判断空满状态。

初始化时，将 `front`、`rear` 和 `tag` 均置为 `0`。入队前检查是否已满，成功后写入元素并推进 `rear`；若首尾指针相等，将 `tag` 置为 `1`。出队前检查是否为空，成功后读取队首元素并推进 `front`；若首尾指针相等，将 `tag` 置为 `0`。

## 主要函数

| 函数 | 作用与返回值 |
| --- | --- |
| `InitQueue()` | 初始化队列，不返回值 |
| `enqueue()` | 插入一个元素；成功返回 `1`，队满返回 `0` |
| `dequeue()` | 通过指针参数传出队首元素；成功返回 `1`，队空返回 `0` |

## 复杂度分析

- 初始化、单次入队和单次出队的时间复杂度均为 `O(1)`。
- 单次操作的辅助空间复杂度为 `O(1)`。
- 队列存储空间随容量增长，为 `O(MaxSize)`；当前固定容量为 `5`。

## 运行示例

程序无需键盘输入，依次执行以下操作：

```text
初始化：空队列
入队 10：10
入队 20：10 → 20
出队一次：取出 10，剩余 20
```

程序预期输出：

```text
10
```
