# 顺序表中指定元素的删除

## 项目介绍

本项目使用 C 语言演示顺序表的原地删除操作：读取整数序列和待删除的值，将所有不等于该值的元素依次移到数组前部，并保持它们的相对顺序。

源代码：[code1.c](./code1.c)。

## 主要功能

- 读取元素个数、整数序列和待删除的值。
- 遍历数组，将需要保留的元素压缩到数组前部。
- 输出删除后的序列。

## 算法原理

采用双下标遍历方式，其中 `i` 表示当前读取位置，`m` 表示下一个保留元素的写入位置。

1. 将 `m` 初始化为 `0`。
2. 从左到右遍历原数组。
3. 若 `a[i] != item`，将该元素写入 `a[m]`，随后令 `m` 加一；否则跳过该元素。
4. 遍历结束后，数组前 `m` 个元素构成删除后的有效序列。

该方法无需逐次移动后续元素，也不会改变保留元素的相对顺序。

## 复杂度分析

- 时间复杂度：`O(n)`，其中 `n` 为原数组的元素个数。
- 辅助空间复杂度：`O(1)`，仅使用固定数量的变量，直接在原数组上操作。

## 操作示例

依次输入元素个数 `5`、序列 `1 2 3 2 4` 和待删除的值 `2`。

算法预期的有效序列为：

```text
1 3 4
```

当前程序实际输出的数字序列为：

```text
1 3 4 4
```
