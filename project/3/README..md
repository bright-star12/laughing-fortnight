# 基于栈的回文字符串判断

## 项目介绍

本项目使用 C 语言和顺序栈判断输入字符串是否为回文。回文是指从左向右和从右向左读取时完全相同的字符序列，例如 `abba` 和 `abcba`。

源代码：[code3.c](./code3.c)。

## 主要功能

- 读取一个不含空白字符的字符串。
- 将字符串前半部分压入栈中。
- 利用栈的后进先出特性比较字符串两半是否对称。
- 输出“是回文”或“不是回文”。

## 算法原理

1. 计算字符串长度 `len`，并确定中间位置 `mid = len / 2`。
2. 将前 `mid` 个字符依次入栈。
3. 若长度为奇数，跳过中间字符；若长度为偶数，从后半部分的第一个字符开始比较。
4. 依次弹出栈顶字符，与后半部分字符逐一比较。
5. 若出现不匹配，立即返回 `0`；若全部匹配，则返回 `1`。

例如，输入 `abcba` 时，先将 `a`、`b` 入栈，跳过中间的 `c`，再按 `b`、`a` 的顺序弹栈并比较。

## 复杂度分析

- 时间复杂度：`O(n)`，其中 `n` 为字符串长度。
- 按输入长度扩展容量时，辅助空间复杂度为 `O(n)`，栈最多保存约一半字符。
- 当前实现固定分配 `MAXSIZE` 个字符的栈空间，其中 `MAXSIZE = 100`。

## 输入与输出示例

| 输入 | 预期输出 |
| --- | --- |
| `abba` | 是回文 |
| `abcba` | 是回文 |
| `abcd` | 不是回文 |
| `a` | 是回文 |

- `IsPalindrome()` 返回 `1` 表示是回文，返回 `0` 表示不是回文。

## 不足

- 当前代码使用 `scanf("%s", s)` 读取输入，遇到空格、制表符或换行时停止，无法直接判断包含空白的整句文本。
- 输入数组容量为 `100`，需为字符串结束符保留一个位置，因此输入应最多包含 `99` 个字节。
- 比较按字节进行，区分大小写，不会忽略标点；不适合直接判断 UTF-8 中文等多字节字符构成的回文。
