# 两个有序单链表的合并

## 项目介绍

本项目使用 C 语言将两个带头结点的升序单链表合并为一个有序链表。合并过程复用已有结点；当两个当前结点的值相等时，保留第一条链表的结点，并释放第二条链表对应的结点。

源代码：[code2.c](./code2.c)。

## 主要功能

- 根据整数数组创建带头结点的单链表。
- 比较并连接两个有序链表中的结点。
- 对合并过程中两条链表当前值相等的结点进行合并处理。
- 遍历并输出合并结果。

## 算法原理

使用 `pa` 和 `pb` 分别遍历两个链表，使用 `pc` 指向结果链表的尾结点。

1. 以第一条链表的头结点作为结果链表的头结点。
2. 比较 `pa` 与 `pb` 的数据值，将值较小的结点接到结果链表尾部，并推进对应指针。
3. 若两者相等，将 `pa` 接入结果链表，同时释放 `pb`，再推进两个遍历指针。
4. 当其中一条链表遍历结束时，将另一条链表的剩余部分直接接到结果链表尾部。
5. 释放第二条链表的头结点，返回结果链表。

## 主要函数

| 函数 | 作用 |
| --- | --- |
| `createlist()` | 根据数组创建带头结点的单链表 |
| `mergelist()` | 原地合并两个有序链表，并处理当前值相等的结点 |
| `printlist()` | 遍历链表并输出各结点的数据 |

## 复杂度分析

- 合并时间复杂度：`O(m + n)`，其中 `m`、`n` 分别为两个链表的数据结点数。
- 合并辅助空间复杂度：`O(1)`，仅使用固定数量的指针，不创建新的数据结点。
- 创建两个链表所需的结点存储空间：`O(m + n)`。

## 运行示例

程序使用内置数组，无需从键盘输入：

```text
链表 A：1 → 2 → 3
链表 B：3 → 4 → 5
合并结果：1 → 2 → 3 → 4 → 5
```

按当前输出格式，程序预期显示：

```text
12345
```

## 不足

- 输入链表必须按非递减顺序排列；当前代码不会检查或排序输入数据。
- 若每条输入链表内部均无重复值，合并结果也无重复值；若单条链表内部含有重复值，当前逻辑不能保证结果完全去重。
- `printlist()` 未在数字之间添加分隔符，多位数输出可能难以区分。
